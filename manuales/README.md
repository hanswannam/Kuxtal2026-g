## Cómo usar estos manuales

- **Markdown puro**: abrilos en cualquier editor (VS Code, Notion, Obsidian, GitHub).
- **Convertir a PDF**: usá una extensión de markdown a PDF, o pegá el contenido en Google Docs.
- **Compartir**: ideal para onboarding de nuevos administradores, socios y comercios.
